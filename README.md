# Niurix Website (Next.js 16)

This project is migrated to Next.js App Router.

## Runtime Entry Points
- `app/layout.tsx` (root layout)
- `app/page.tsx` (homepage route)
- `app/globals.css` (global styles + Tailwind v4)

There is no `app.tsx` in App Router architecture.

## Run
- `npm run dev`
- `npm run typecheck`
- `npm run lint`
- `npm run build`
