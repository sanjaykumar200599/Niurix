# Niurix — React.js to Next.js Migration

A production-focused migration of the **Niurix web application from React.js to Next.js**, with a strong focus on JavaScript/TypeScript development, application performance, SEO, scalability, and maintainability.

## 🚀 Overview

Niurix was migrated from a React.js application to **Next.js with TypeScript**, improving the application's architecture, performance, scalability, and SEO.

The project involved working with an existing JavaScript codebase, migrating React components and application logic, integrating REST APIs, optimizing rendering, and preparing the application for production deployment.

## ✨ Key Highlights

* Migrated a production **React.js application to Next.js**
* Developed and maintained reusable **React components**
* Worked extensively with **JavaScript and TypeScript**
* Converted and structured application logic using TypeScript
* Implemented server-side rendering with Next.js
* Improved application scalability and maintainability
* Integrated and validated **REST APIs**
* Handled JSON-based data workflows
* Optimized JavaScript application performance
* Improved SEO/performance score from **11 to 95**
* Built responsive interfaces for desktop, tablet, and mobile
* Debugged JavaScript, API, rendering, and integration issues
* Used Git/GitHub workflows and code reviews
* Collaborated with the engineering team using Agile practices
